# DAO Core Contract

The foundational contract for decentralized autonomous organizations, handling
key components such as membership, proposals, and governance logic.

## Key Functions
- `register-member` — Add a new member to the DAO
- `create-proposal` — Submit a new governance proposal
- `vote` — Cast votes on active proposals
- `execute-proposal` — Carry out approved decisions
- `get-member-info` — Retrieve membership details

Designed for DAOs seeking a modular, on-chain governance and operational framework.
